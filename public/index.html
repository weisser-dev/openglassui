Set up the local companion, then connect your Meta Ray-Ban Display through Meta AI on your phone.

  1. Enable developer mode for web apps in the Meta AI app.
  2. Start an HTTPS connection to the gateway, or use an existing HTTPS address. Never expose the local dashboard port.
  3. Create a pairing code and scan it with your phone. The code is single-use and expires after five minutes.
  4. Add the web app in Meta AI, open it on your glasses, and test its controls.

Keep the pairing code private. Anyone who redeems it can access your approved projects.
